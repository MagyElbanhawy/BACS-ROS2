# Paper traceability

This document maps the paper's reproducibility claims to the implementation,
frozen outputs, and preserved evidence. A claim is only marked reproducible when
the repository contains both the relevant code and the data needed to run it.

| Paper surface | Implementation | Frozen output / evidence | Reproduction status |
|---|---|---|---|
| S1-S6 baseline simulation | `bacs_sim/experiments.py`, `scripts/reproduce.py` | `results/` generated by the script | Reproducible from code; not rerun by this import |
| Progression | `bacs_sim/experiments.py::progression` | `paper_results/progression.csv` | Frozen output present; regeneration path present |
| S7-C incremental surrogate validation | `bacs_sim/experiments.py::s7c_incremental_validation`, `s7c_paired` | `paper_results/s7c_*.csv` | Frozen output present; regeneration path present |
| S8 held-out 30-seed evaluation | `scripts/run_s8_30seed.py` | `paper_results/s8_30seed_*.csv` | Frozen output present; regeneration path present |
| S9 deferral-derived gamma | `bacs_sim/experiments.py::s9_deferral_gamma` | `paper_results/s9_deferral_gamma.csv` | Frozen output present; regeneration path present |
| Publication figures | `scripts/make_figures.py` | `paper_figures/*.png` | Reproducible from frozen CSVs |
| ROS 2 BACS/BACS+ scheduler | `ros2_ws/src/bacs_scheduler` | package, messages, launch/config, node scripts | Source implementation present; hardware execution environment required |
| Physical Table 6 RMSE | `analysis/physical/table6_physical.py` | raw archive + Vicon/scheduler logs | **Not independently reproducible from current archive**: no per-run map-alignment metric or map estimate stream |
| Physical communication diagnostics | `analysis/physical/table6_physical.py`, `analysis/physical/scheduler_log_parser.py` | raw scheduler CSVs | Available fields recomputed; paper headline delay targets are not reproduced |
| Physical ten-run count | `hardware/tools/validate_hardware_dataset.py` and session logs | `session_manifest.csv`; scheduler `run` values 1-10 | Verified as a run-index declaration and run labels; metric matching remains separate |

## Interpretation rules

- `paper_results/` contains frozen simulation outputs, not newly generated claims.
- Raw physical files under `hardware/raw/` are immutable evidence and are not
  altered to make a paper value fit.
- A missing metric is reported as unavailable rather than replaced with a
  manuscript number.
- The raw archive records RYLR998 at 433 MHz; the manuscript's 868 MHz statement
  is an explicit mismatch documented in `AUDIT_REPORT.md`.
